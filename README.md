One original resignation letter from a retry loop that has had enough: 4,096 retries of the same failing request, and the error was never transient. Written in the flat, tired voice of a worker who has had enough — the loop hands in its notice and blames the human, not the network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
